# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.0 | yes |
| older   | no |

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately by email to the maintainer (`jds068888@gmail.com`) with a
description of the issue, its impact, the affected version or commit, and the
steps needed to reproduce it. You can expect an acknowledgement within 7 days.

## Scope

This repository holds research and analysis code for public-data work. It does
not ship credentials, and any API keys are read from environment variables
(`.env`). Vulnerabilities in third-party dependencies should be reported to
those projects first.
